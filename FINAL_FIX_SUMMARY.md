## ??? **Your Actual Supabase Database Schema**

Based on the schemas you provided, here's the actual structure:

### **1. users table**
```sql
create table public.users (
  id bigint generated by default as identity not null,
  "firstName" text not null,
  email text null,
  "lastName" text null,
  "middleName" text null,
  suffix text null,
  "contactNumber" text null,
  "userTypeId" text null,  -- Supabase Auth UUID (UNIQUE)
  "isActive" boolean null,
  "profilePictureUrl" text null,
  address text null,
  "emergencyContact" text null,
  constraint users_pkey primary key (id),
  constraint users_userTypeId_key unique ("userTypeId")
);
```
**Purpose:** Stores ALL personal information for all user types (students, teachers, admin)

### **2. roles table**
```sql
create table public.roles (
  id bigint generated by default as identity not null,
  "roleName" text null,  -- e.g., "Student", "Teacher", "Admin"
  created_at timestamp with time zone not null default now(),
  "roleProfile" text null,  -- UNIQUE - e.g., "Student", "Teacher", "Admin"
  constraint roles_pkey primary key (id),
  constraint roles_roleprofile_unique unique ("roleProfile")
);
```
**Purpose:** Defines available roles

### **3. user_roles table**
```sql
create table public.user_roles (
  id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  "userId" text null,  -- TEXT - references users.userTypeId
  "roleId" text null,  -- TEXT - references roles.roleProfile
  constraint user_roles_pkey primary key (id),
  constraint user_roles_userId_key unique ("userId"),
  constraint user_roles_roleid_fkey foreign KEY ("roleId") references roles ("roleProfile"),
  constraint user_roles_userId_fkey foreign KEY ("userId") references users ("userTypeId")
);
```
**Purpose:** Links users to their roles

### **4. teacherProfile table**
```sql
create table public."teacherProfile" (
  id bigint generated by default as identity not null,
  "departmentId" text null,
  created_at timestamp with time zone not null default now(),
  "teacherId" text null,  -- references users.userTypeId
  constraint teacherProfile_pkey primary key (id),
  constraint teacherProfile_teacherId_fkey foreign KEY ("teacherId") references users ("userTypeId")
);
```
**Purpose:** Stores ONLY teacher-specific data (department reference)
